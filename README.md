# CM1005 Mario Game Project code

Mario Game project final hand in code for CM1005.

University of London, Computer Science.

Open the folder with a local server, then visit the printed address. Loading `index.html` as a file will not fetch the level data.

```bash
python3 -m http.server
```

```bash
php -S localhost:8000
```

Controls:

- A: move left
- S: move right
- Space: jump
- Shift: run

Four levels. Reach the flag to advance. The bear starts with three lives.
